IoT Platform collects data from your devices (for example an ESP32 with sensors), shows it on a dashboard, lets you switch actuators such as pumps and lamps, and reacts automatically with rules, alarms and notifications.

Main ideas

DeviceOne physical board, e.g. "Greenhouse node". Every device has a secret access token that it uses to send data.
VariableOne value of a device, identified by a key such as temperature. A sensor variable is only read; an actuator variable can also be switched or set from the platform.
TelemetryThe readings a device sends, e.g. {"temperature": 25.1, "humidity": 60}. Each reading is stored with its time.
LocationA place on the map that groups devices, e.g. "Lab 3" or "Greenhouse A".
RuleAn automation, e.g. "if soil moisture is below 20 % for one minute, switch the pump on and raise an alarm".
AlarmA problem raised by a rule. Someone acknowledges it; it clears when the cause is gone.

Your first device in five steps

  1. Create an account and activate it with the link in the email (Your account).
  2. Add a device: Devices → Add device. Give it a name; type, location and description are optional.
  3. Send data. Open the device page and copy its access token. The quickest test is a single command from a computer: 
    curl -X POST {{ http.telemetry }} -H "Content-Type: application/json" -d '{"temperature": 25.1}'
    Replace <token> with the access token. For a real board, follow Connect an ESP32.
  4. Watch the data. The variable temperature is created automatically and appears on the device page and the dashboard (Dashboard, charts and history).
  5. Automate. Create a rule that reacts to the data (Rules overview).

Most pages also have a Help button that opens the matching chapter.

On a large screen, the button next to IoT Platform at the top of the menu hides the menu to give the page more room; the button in the top-left corner shows it again. Your choice is remembered in this browser. On a small screen the menu opens from the ☰ button.

Live updates

Pages with data update by themselves. The switch Live updates at the top of those pages shows the state of the connection and can pause updates. While you type in a form, the page waits until you are done, so nothing you typed is lost.
