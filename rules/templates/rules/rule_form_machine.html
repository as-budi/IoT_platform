{# ---------- 3. Transitions ---------- #}

3 Transitions

From the device's current state, the rows are checked from top to bottom; the first one whose trigger holds moves the device. * means “from any state”.

  • Condition: comparisons joined with and / or (and binds first), e.g. temperature > 35 and humidity < 40 or temperature > 45. ON/OFF may be written for on/off values. “for N s” = the condition must hold that long.
  • After some time: N seconds in the source state (a transition back to the same state repeats its actions every N s).
  • No data / offline: the device is quiet for N s, or its status turns offline.
  • Button: shown on the rule page for each device; pressing it needs Operator access to the device.
