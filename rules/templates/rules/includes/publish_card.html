Publish sends one message to every device in this rule over MQTT: the rule JSON with a "publish" key added in front, either Full (the JSON tab as it is) or Compact (no empty values or description, devices written as their position in "devices"). Each device finds itself by its MAC address in "devices". The table shows which devices confirm that they received it. Devices do not run the rule yet. Topics and replies
