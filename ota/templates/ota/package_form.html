Name tells programs apart: devices with the same board can run different programs. It must match #define FW_TITLE "..." in the sketch (capital letters do not matter). The same version can be uploaded again under another name, but not twice for the same name and board.

Version must be exactly what the new firmware reports after it starts (e.g. #define FW_VERSION "1.2.0"). That report is how the platform knows the update worked.

The server computes the MD5 and SHA-256 checksums. The device checks the MD5 before it switches to the new firmware.
